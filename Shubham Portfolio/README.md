# Shubham Arya Portfolio

Responsive portfolio for UI/UX design and web development, with 11 project detail views, a one-page resume, a WhatsApp inquiry link and an introduction video.

## Live website

https://shubham-protofolio.vercel.app

Deployed directly to Vercel. GitHub synchronization is pending write access to `Shubh12-577/Shubham-protofolio`.

## Source

`site/` contains the complete deployable website. The top-level `index.html` is a local convenience copy; edit and publish the canonical `site/` directory.

## Vercel

Import this repository into Vercel using the repository root. The included `vercel.json` selects the Other framework preset, skips building and publishes `site/`.

## Preview locally

Run `python -m http.server 5173 --directory site` and open http://localhost:5173.

## Notes

Self-initiated interface concepts are labelled separately from documented development work. Video starts when visible; browser policies can require the visitor to press Play with sound.
